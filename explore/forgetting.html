The Geometry of Forgetting

A network that learns a second set of regions does not simply add them to the first. It overwrites them. Below you can train one in your browser, watch it forget, and then look at the shape of the loss surface that explains why.

1

The setup

Indoor localization is a good place to meet this problem. A model is trained to map a Wi-Fi fingerprint to a region of a building. Later, the building gains new regions — a new wing, a new floor — and the model has to learn them from data that contains only the new regions. Nobody re-collects the old wing.

The toy version below keeps that structure and throws away everything else. Four regions live in a 2-D plane. Task A teaches regions 1 and 2. Task B then teaches regions 3 and 4, and Task B's data contains no examples of regions 1 or 2 at all.

Forgetting is the drop from the best Task A accuracy the model ever reached to what is left at the end. Switch to Replay — a small buffer of old samples mixed into each batch — or EWC, which penalises movement in the directions Task A cared about, and run it again.

EWC is worth pushing to its limits. Drag its λ up gradually and the two lines converge: Task A is preserved and Task B is still learned. Keep going and the run collapses — Task A freezes near 50% and Task B never gets off the floor, because the penalty has made the weights too rigid to fit anything new. That is the stability–plasticity trade-off, and it is the reason continual learning is not solved by simply turning regularisation up.

3

The loss landscape

Accuracy curves tell you that forgetting happened. To see why, look at the shape of Task A's loss around the weights. The network lives in ~750 dimensions, so we take a 2-D slice: pick two random directions and walk along them.

f(α, β) = LA( θ* + α·δ + β·η )
θ*
The weights at the centre of the plot.
δ, η
Two random directions, filter-normalised so the two panels are comparable.
LA
Loss on Task A only — the knowledge we are asking about.

Filter normalisation matters. Without it, a network with larger weights looks flatter purely because the same step size moves it less, and the comparison is meaningless. Scaling each neuron's direction to that neuron's own weight norm removes it.

With naive fine-tuning the centre of the right-hand panel is no longer in the blue. The optimiser walked out of Task A's basin entirely while it was minimising Task B. With replay or EWC the two panels stay far more alike — the solution stays inside a region that is still good for the first task.

If Task A's loss climbs steeply and never comes back down, the two solutions sit in different basins and the first task is gone. A low barrier means both models are in the same wide valley, and the knowledge survived the trip.

5

What this means for real systems

The toy is 2-D, but the failure is the one that shows up in deployment. In smartphone-based indoor localization the "new task" arrives constantly: a new region opens, a device model changes its radio behaviour, a building's Wi-Fi infrastructure gets reconfigured. Each of those is a distribution the model must absorb without a full retrain, and each is an opportunity to overwrite what already worked.

Replay and EWC are the two blunt instruments shown here. The papers below go further — class-incremental path learning that grows capacity instead of overwriting it (CIELO), disentangled representations that separate device drift from genuine location change (DAILOC), and expert routing that keeps regions in separate parameter subspaces so they cannot collide at all (MOELO).
